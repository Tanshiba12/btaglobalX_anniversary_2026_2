# BTA GLOBALx Event Website - Block-Color Asset Plan

## 1. Purpose

This asset plan supports the NVG8-inspired refactor: solid-color editorial visuals, SVG-style objects, stickers, cutouts, passes, magazine pages, and custom motion props.

The user can generate many of these assets with Freepik Premium. Prompts below are written to avoid fake logos, fake text, and unusable blended backgrounds.

Global prompt rule:

> premium playful editorial vector, solid colors, flat fills only, no fake text, no logos, transparent background where possible
