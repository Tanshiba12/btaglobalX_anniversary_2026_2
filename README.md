# BTA GLOBALx Anniversary 2026

One-page block-color GSAP event website prototype for BTA GLOBALx Anniversary Gala Night & Excellence Award 2026.

## Development

```bash
npm install
npm run dev
```

The app uses the planning docs in `plan/updated` as its source direction. Current visuals are CSS/SVG-style placeholders for stamps, stickers, passes, plaques, magazine pages, and scrapbook tiles so official logos, speaker portraits, gallery media, and generated Freepik assets can be swapped in later.
